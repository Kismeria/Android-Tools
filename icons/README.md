# AT Icons

Icon font for platforms without Segoe Fluent Icons (Linux, Windows 10). Each glyph uses the same
code point as its Segoe Fluent Icons counterpart (`map.txt`), so the UI markup stays the same.

Glyphs: [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) by Microsoft, MIT License.

Rebuild: `pip install fonttools brotli && python build_font.py` (run inside this folder).
